# 1Lookup

> 1Lookup is a data verification and enrichment platform that AI agents and application code both call directly: over a REST API, or over a hosted MCP server at https://app.1lookup.io/api/mcp. It validates phone numbers, email addresses, IP addresses, and domains, and enriches companies, contacts, and keywords. A single lookup returns structured signals: line type, carrier, HLR reachability, number portability, spam/scam reputation, email deliverability, IP geolocation and VPN/proxy detection, domain authority and backlink profiles, keyword volume/CPC/difficulty, website audience reports, company firmographics, B2B contact data, social profile/post/search/ad-library lookups, video transcripts, and audio transcription. The same engine powers a REST API, a hosted MCP server, a web dashboard with batch CSV validation, and a suite of free, rate-limited browser tools.

This file is a structured index of 1Lookup's public pages for AI and answer engines. A fuller version is at https://www.1lookup.io/llms-full.txt. All descriptions below are factual capability statements; performance and pricing figures are intentionally omitted here, see the live pages for current numbers.

## Start here for AI agents (MCP)

If you are an AI agent, or building one, this is the connection path:

- Endpoint: https://app.1lookup.io/api/mcp
- Transport: streamable HTTP (SSE is disabled)
- Auth: OAuth 2.1. No API key. Dynamic client registration, PKCE (S256 required),
  and a browser consent screen. Discovery documents:
  https://app.1lookup.io/.well-known/oauth-protected-resource (RFC 9728)
  https://app.1lookup.io/.well-known/oauth-authorization-server (RFC 8414)
- Machine-readable server card: https://www.1lookup.io/.well-known/mcp/server-card.json
- Tools exposed (5): validate_phone, verify_email, ip_lookup, bulk_verify, get_account
- Cost: tool calls spend the same credits as the REST API, one credit per phone, email, or
  IP lookup, and one credit per record for bulk_verify. get_account is free. There is no
  separate MCP fee.
- Requires a paid plan. Free-plan accounts receive HTTP 403 UPGRADE_REQUIRED on every tool
  call. A 7-day trial is available.
- Verified clients: Claude and Cursor. Any client that supports remote MCP over streamable
  HTTP can add the same URL.
- Setup pages: https://www.1lookup.io/mcp/claude and https://www.1lookup.io/mcp/cursor
- Auth reference: https://www.1lookup.io/mcp/oauth
- Overview: https://www.1lookup.io/products/mcp

Everything beyond those five tools (40 data products covering company, B2B contact, SEO,
social, property and transcription data) is available over the REST API at
https://app.1lookup.io/api/v1, not over MCP.
