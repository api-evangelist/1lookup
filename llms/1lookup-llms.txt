# 1Lookup

> 1Lookup is a data verification and enrichment platform that validates phone numbers, email addresses, IP addresses, and domains, and enriches companies, contacts, and keywords. A single lookup returns structured signals: line type, carrier, HLR reachability, number portability, spam/scam reputation, email deliverability, IP geolocation and VPN/proxy detection, domain authority and backlink profiles, keyword volume/CPC/difficulty, website audience reports, company firmographics, B2B contact data, social profile/post/search/ad-library lookups, video transcripts, and audio transcription. The same engine powers a REST API, a web dashboard with batch CSV validation, and a suite of free, rate-limited browser tools.

This file is a structured index of 1Lookup's public pages for AI and answer engines. A fuller version is at https://www.1lookup.io/llms-full.txt. All descriptions below are factual capability statements; performance and pricing figures are intentionally omitted here, see the live pages for current numbers.
